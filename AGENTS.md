# AGENT GUIDANCE

## Project scope

- Build a clean, form-driven React experience on top of Vite, using Tailwind-styled components, that helps visitors describe their website/app and then generates a privacy policy draft based on that input.
- Keep the UI responsive, on-brand, and focused on the dual-pane workflow: edit metadata on the left and instantly preview the policy on the right.
- Preserve the tooling stack (pnpm, eslint, shadcn components, Tailwind-like utilities) established during project setup.

## Operational instructions

- When reviewing or verifying files, always open them directly in VS Code. Do not rely on Python scripts, PowerShell commands, or other CLI programs to read file contents; use the editor to ensure you see the latest version.
- If you need to make filesystem changes, prefer VS Code tools or the prescribed apply_patch/create_file utilities rather than shell-based file manipulation steps.
